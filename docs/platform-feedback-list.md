# Mongolian Massagelab — Platform Feedback & Fix List

## 1. Calendar / Schedule

**1.1 — Cancelled appointments not removed from calendar**
When an appointment is cancelled and a new one is booked around the same time, the cancelled appointment stays visible on the calendar and blocks the view of the new appointment. Cancelling an appointment should remove it from the calendar entirely (not just mark it cancelled in the background).

**1.2 — Drag-and-drop rescheduling**
From the calendar, allow dragging an appointment to a different time slot and/or a different room.

**1.3 — Edit appointment directly from calendar**
Clicking an appointment on the calendar should allow editing it: change the service, add add-on services, and apply a discount.

---

## 2. Booking Flow

**2.1 — Couple / four-hands massage: no availability shown when picking specific therapists**
When booking a couple's massage or a four-hands massage and choosing specific therapists, the system doesn't show available time slots — it only indicates that 2 therapists are needed, without letting us see/pick an actual time.

**2.2 — "No preference" auto-assigns a therapist**
When "No preference" is selected, the system automatically books the appointment with a specific therapist. Instead, it should be possible to:
- Leave the appointment as "No preference" (unassigned) at booking time
- Afterward, open/edit that appointment from the schedule and assign a specific therapist to it
- Add internal notes to the appointment at that point as well

---

## 3. Checkout

**3.1 — Request client feedback before checkout/completing appointment**
Before an appointment is checked out or marked complete, the system should prompt for the client's rating on a 1-10 scale. This will be collected at the front desk on either a pad (touchscreen) or desktop, so the prompt needs to display clearly and specifically on both.

**3.2 — Add deposit and discount fields**
The checkout screen needs a deposit section and a discount field.

**3.3 — Simplify the checkout flow**
Currently, going from check-in to checkout requires too many steps/buttons. Instead:
- From the calendar, clicking an appointment should show a **Checkout** button directly (skip the multi-step check-in process)
- Next to Checkout, add a **3-dot menu** with:
  - Cancel
  - No-show
  - Rebook
  - Reschedule
  - Add notes
  - Set as repeating appointment

---

## 4. Clients

**4.1 — Add a ratings column to visit history**
In the client's visit history, add a column showing the rating given for each visit.

**4.2 — Show gift card purchase info**
The client profile should display any gift cards the client has purchased.

---

## 5. Staff Earnings

**5.1 — Simplify earnings entry**
Instead of manually adding a "quantity" for each session a staff member works (which is cumbersome and can't be edited afterward), allow earnings to be entered/edited directly in a column, with the ability to go back and edit the value later.

---

## 6. Service Menu

**6.1 — Edit existing services**
Allow editing the name and session length(s) of services that already exist in the system.

---

## 7. Gift Cards

**7.1 — Manual code entry or auto-generated code**
When creating a gift card, allow entering a specific number/code for it. If no code is entered, the system should auto-generate one for the gift card being sold.
